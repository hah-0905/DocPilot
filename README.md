# DocPilot

DocPilot 是一个多知识库智能问答与报告生成平台，基于 RAG 技术实现文档解析、知识库管理、语义检索、问答生成与报告生成。

## 技术栈

- Backend: FastAPI
- Database: MySQL
- Vector Database: 待定
- Embedding Model: 待定
- LLM: 待定
- Frontend: Vue / React 待定
